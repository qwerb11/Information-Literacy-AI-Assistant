AI 模型配置

选择预设后自动填充下方地址与模型名；也可选「自定义」手动填写。
填 OpenAI 兼容接口的根地址，末尾带不带 / 均可。
⚠️ 安全提示：API Key 仅保存在本机浏览器（localStorage），不会上传到任何第三方。不要把含 Key 的这个文件直接发给学生或公开分享，否则他人可提取 Key 盗刷你的账户。
💰 费用提示：每次提问都会产生 token 消耗，请在模型平台（如 DeepSeek 开放平台、阿里云百炼）充值，并在平台上设置单日消费上限。
🔧 跨域提示：若测试连接提示 CORS/跨域错误，说明该服务商禁止浏览器直接调用，请换用支持浏览器调用的 OpenAI 兼容接口服务商。
